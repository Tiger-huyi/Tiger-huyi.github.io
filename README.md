# 虎義 HUYI 个人网站

公开地址：<https://tiger-huyi.github.io/>

这是一个无构建依赖的静态网站，使用 HTML 与 CSS 实现。视觉采用白、黑、粉三色的瑞士国际主义风格。

## 页面

- `index.html`：首页与个人介绍
- `updates/index.html`：最近动态归档
- `designs/index.html`：随手设计归档
- `photos/index.html`：摄影归档
- `works/index.html`：旧作品集兼容入口，自动前往随手设计
- `404.html`：未找到页面
- `styles.css`：全站网格、字体与响应式样式
- `og-source.svg` / `og.png`：分享图源文件与发布图片

## 本地预览

在仓库目录运行：

```sh
python3 -m http.server 4173
```

打开 <http://localhost:4173/>。修改后至少检查 320、375、768、1024 和 1440px 宽度。

## 添加内容

当前三个内容区使用明确的空状态。收到第一批真实素材后：

1. 将经过网页导出、适合公开的图片放入对应资源目录。
2. 在首页对应栏目加入精选内容。
3. 在归档页加入完整条目。
4. 照片根据实际情况填写摄影者和设备；未提供的字段整行省略。
5. 不把原始照片、位置元数据、私密草稿或演示日期放入公开仓库。
